# Accountant validation checklist

Before Bijoria's first live invoice, validate representative transactions in JewelLAN and the connected test Tally company:

- Telangana intra-state jewellery sale: taxable value, CGST and SGST split.
- Inter-state sale: IGST and place-of-supply state code.
- Cash sale.
- UPI/card sale.
- Customer-credit sale and debtor balance.
- Purchase with supplier outstanding.
- Old-gold exchange treatment used by Bijoria.
- Partial item return / credit note and GST reversal.
- Whole-invoice cancellation/reversal.
- Round-off handling.
- COGS/inventory accounting treatment.
- Day-close sales/payment totals against trial balance and Tally vouchers.

Record any accountant-required ledger/voucher changes before enabling live automatic Tally synchronization.
