# Bijoria install profile

Main PC: choose **Server + Counter + Tally Bridge**.

Counter PCs 2 and 3: choose **Counter only**.

Use a Windows **Private** network. Do not expose JewelLAN or TallyPrime ports to the Internet. After installation, each counter must discover or enter the main-PC JewelLAN HTTPS address and verify the SHA-256 server fingerprint before signing in.
