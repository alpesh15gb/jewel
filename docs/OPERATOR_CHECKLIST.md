# Daily operator checklist

Opening:
- Main PC and JewelLAN Server scheduled task running.
- Both counter PCs connected to the expected pinned HTTPS server.
- Business date is correct for IST.
- Current metal rates reviewed before billing.
- Receipt/A4 and barcode printers available.
- Tally may be offline without blocking billing; any pending sync is reviewed by accounts.

Closing:
- Run day-close and confirm sales/payment and journal balance checks pass.
- Review failed/pending Tally queue items.
- Run Data Health if any unusual error occurred during the day.
- Confirm a verified backup exists for the day according to retention policy.
- Resolve open stock-audit discrepancies through controlled workflows rather than database edits.
