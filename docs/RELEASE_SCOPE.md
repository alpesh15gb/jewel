# JewelLAN 1.2 release scope

Included in the 1.2 production candidate: offline three-PC LAN POS, serialized jewellery stock, barcode/HUID/weight controls, GST billing, purchases, old gold, customer credit, repairs/orders, karigar and approvals, stock audit, double-entry accounting, verified backups/recovery, Data Health/day-close, TallyPrime asynchronous integration, HTTPS certificate-pinned LAN transport, item-level returns/credit notes, safe in-place Windows upgrades and production acceptance documentation.

Optional/vendor-specific items such as direct RFID-reader SDK integration remain hardware-adapter work and are not required for a barcode-first Bijoria go-live.
